# 상명 AI Training · 팀 프로젝트 (7·8·9일차) Tool 기반 AI Agent 시스템

## 개요

* **7일차 팀프로젝트 (AI Agent 목표 및 도구 설계):** 대학생 및 취업준비생의 대외활동·공모전 탐색 비용을 줄이기 위해 에이전트의 목표와 역할을 정의하고, 실시간 웹 탐색·맞춤 추천·파일 관리·코드 실행 등 12종의 핵심 도구(Tools)를 설계함.
* **8일차 팀프로젝트 (미들웨어 설계 및 구현):** 대화 맥락 유지와 사용자 맞춤형 응답 제공을 위해 **Checkpointer 기반 대화 상태 기억**, **사용자 프로필 동적 주입 미들웨어**, **프로필 자동 수집 및 DB 저장 시스템**을 구축하고 통합 테스트를 진행함.
* **9일차 팀프로젝트 (Agent Systems - Skills, Middleware & End-to-End Evaluation):** 특정 복합 태스크를 표준 프로세스로 처리하는 **에이전트 스킬(Skills) 3종**을 정밀 구축하고, 미들웨어 및 도구들이 유기적으로 결합된 LangGraph 스튜디오 환경에서 End-to-End 시나리오 검증 및 최종 결과물 저장을 완료함.

---

## 1. [7일차] AI Agent 목표 및 도구 설계

### 해결하고자 하는 문제 (Problem Statement)

* **정보 파편화 및 탐색 비용 증가:** 링커리어, 캠퍼스픽, 위비티, 콘테스트코리아 등 수많은 대외활동 플랫폼에 정보가 분산되어 있어 일일이 검색하는 데 막대한 시간과 노력이 소모됨.
* **맞춤형 정보 제공의 한계:** 직무, 관심 분야, 선호 혜택에 적합한 공고를 추천받기 어렵고, 합격 후기나 관련 연관 검색어를 함께 파악하기 불투명함.

### Agent의 역할 (Agent Role)

* **통합 탐색 및 실시간 정보 추적:** 주요 플랫폼의 공고를 조건별로 조회하고, 실시간 웹 검색을 통해 최신 공고 및 합격 후기·팁을 도출함.
* **지능형 맞춤 추천:** 사용자의 희망 직무, 관심 분야, 선호 혜택을 다각도로 분석하여 최적의 대외활동 및 공모전을 매칭 점수 기반으로 추천함.

### 도구(Tool) 목록 (12종)

| 도구명 | 입력 (Input) | 출력 (Output) | 주요 역할 |
| --- | --- | --- | --- |
| **`search_platform_activities`** | `platform`, `keyword`, `category`, `start_date`, `end_date` | 공고 목록 (JSON) | 주요 대외활동 사이트 공고를 조건별 통합 조회 |
| **`get_activity_url`** | `activity_id`, `title` | 원본 URL 및 안내 문구 | 대외활동 원본 모집 페이지 상세 링크 안내 |
| **`recommend_by_user_preference`** | `user_interests`, `target_job`, `preferred_benefit` | 맞춤 공고 목록 (JSON) | 희망 직무 및 선호 혜택 기반 매칭 점수 추천 |
| **`recommend_related_trending`** | `query`, `sort_by` | 연관 검색어 및 인기 게시글 (JSON) | 연관 키워드 도출 및 인기/최신 합격 후기·팁 연계 추천 |
| **`search_daeo_activities_websites`** | `query`, `max_results` | 검색 결과 문자열 | 8개 주요 대외활동 전문 플랫폼 타겟 실시간 웹 검색 |
| **`search_web`** | `query`, `max_results` | 검색 결과 문자열 | 일반 웹 영역 실시간 검색 (대외활동 중복 여부 구분) |
| **`read_file`** | `file_path` | 텍스트 내용 및 총 줄 수 | 로컬 저장소의 자소서, 메모 등 텍스트 파일 읽기 |
| **`write_file`** | `file_path`, `content` | 성공/실패 메시지 및 총 줄 수 | 지원서 초안, 요약본 파일 생성 및 내용 작성 |
| **`delete_file`** | `file_path` | 성공/실패 메시지 | 불필요한 임시 파일 및 기존 파일 삭제 |
| **`create_directory`** | `dir_path` | 성공/실패 메시지 | 지원 관리용 폴더(디렉터리) 생성 |
| **`list_directory`** | `dir_path` | 파일/폴더 목록 문자열 | 폴더 내부 구조 및 파일 크기 조회 |
| **`execute_python_code`** | `code` | 코드 실행 결과 (stdout, stderr) | 작성된 파이썬 코드 실제 실행 및 데이터 가공/연산 |

## 2. [8일차] 미들웨어 설계, 구현 및 테스트

### 미들웨어 설계

1. **Checkpointer 활용 세션 및 대화 상태 기억 미들웨어**
   * 사용자 `session_id` 또는 `thread_id` 기반으로 이전 대화 맥락과 진행 상태를 유실 없이 기억.
   * 여러 단계의 도구 호출(Tool Calling) 과정에서도 유저의 최초 의도와 연속된 질문 흐름 유지.

2. **사용자 프로필 동적 주입 미들웨어**
   * 에이전트 실행 시, DB에 저장된 사용자의 희망 직무, 관심 분야, 작성된 자소서 정보 등 **개인화 프로필**을 시스템 프롬프트에 실시간 주입.
   * 유저가 매번 자신의 스펙이나 희망 사항을 재입력하지 않아도 개인 맞춤형 공고 추천 및 답변 제공.

3. **프로필 수집 및 저장 구현 코드**
   * 대화 과정에서 자연스럽게 드러나는 유저의 정보(예: "난 철수고 대학교 3학년이야")를 감지 및 추출.
   * 감지된 사용자 특성을 DB에 자동으로 업데이트 및 저장하는 비동기 미들웨어 파이프라인 구현.

## 3. [9일차] Agent Systems (Skills, Middleware & End-to-End Evaluation)

### 프로젝트 개요

9일차 프로젝트에서는 구축된 12종의 도구와 미들웨어를 기반으로, 사용자의 고도화된 요청을 일관되고 정교하게 처리하기 위한 **3가지 핵심 에이전트 스킬(Agent Skills)**을 적용했습니다. 또한 LangGraph Studio 환경에서 다중 도구 연쇄 호출(Tool Chaining), 상태 유지, 로컬 파일 시스템 연동을 포함한 통합 엔드투엔드(End-to-End) 파이프라인 검증을 완료했습니다.

---

### 구축된 에이전트 스킬(Skills) 시스템

#### 1. `activity-search-and-analysis` (대외활동 조건 검색 및 URL 탐색 스킬)
* **설명:** 사용자가 특정 분야, 조건, 관심사 기반의 대외활동이나 공모전을 찾을 때, 조건 검색부터 원본 상세 정보 안내까지 체계적으로 제공합니다.
* **프로세스:**
  1. **사용자 요구사항 분석 및 조건 검색:** `search_platform_activities` 도구를 활용해 공고 목록 조회 (필요시 `search_daeo_activities_websites` 병행)
  2. **매칭 점수 기반 필터링 및 원본 URL 추출:** 상위 공고 엄선 후 `get_activity_url`로 원본 접수 페이지 링크 확보
  3. **구조화된 요약 및 맞춤 추천 결과 전달:** 공고명, 모집기간, 주요혜택, 원본URL 및 추천 사유 요약 제공

#### 2. `trending-and-review-finder` (트렌드 및 합격 후기 심층 탐색 스킬)
* **설명:** 특정 대외활동/공모전의 합격 후기, 지원 팁, 관련 연관 정보나 인기 콘텐츠를 찾아서 정리해 줄 때 사용합니다.
* **프로세스:**
  1. **연관 콘텐츠 및 트렌드 정보 조회:** `recommend_related_trending` 도구로 연관 검색어 및 인기 게시글 정보 조회
  2. **심층 후기 웹 검색:** `search_web` 또는 `search_daeo_activities_websites`로 실시간 합격 후기 및 면접 팁 탐색
  3. **핵심 합격 노하우 요약 및 제공:** 서류/자소서 작성 팁, 면접 준비 포인트, 우대사항 카테고리별 정리

#### 3. `activity-data-analyst` (파이썬 코드 기반 대외활동 데이터 가공·연산 스킬)
* **설명:** 수집된 대외활동 및 공모전 데이터(마감일, 활동비, 경쟁률 등)를 파이썬 코드로 가공·연산하여 객관적인 통계 분석 결과를 제공합니다.
* **프로세스:**
  1. **대외활동 데이터 수집 및 구조화:** `search_platform_activities` 호출로 조건에 맞는 공고 리스트(JSON) 확보
  2. **Python 코드를 활용한 데이터 가공 및 연산:** `execute_python_code` 도구로 D-day 계산, 활동비/상금액 정렬 코드 실행
  3. **분석 결과 및 시각화 요약 제공:** 정렬된 최고액 공고, 마감 임박 순서 등 통계 표 결과 출력

### 검증용 시나리오 예시 질문 (5선)

1. **질문 1 (조건별 탐색 및 URL 추출):**  
   > "서울 지역에서 참여할 수 있는 대학생 마케팅 서포터즈 찾아줘. 수료증이나 활동비 지급되는 공고 위주로 추천하고 신청 원본 링크도 같이 줘."

2. **질문 2 (합격 후기 및 지원 팁 탐색):**  
   > "이번에 SK 대학생 자원봉사단 SUN에 지원하려고 하는데, 최근 실제 합격자들의 자소서 작성 팁이랑 면접 자주 나오는 질문 정리해줘."

3. **질문 3 (파이썬 데이터 연산 및 분석):**  
   > "이번 달 마감 예정인 IT/개발 공모전 10개 조회해서 상금 규모가 가장 높은 상위 3개만 파이썬 코드로 계산해서 순위대로 정렬해 보여줘."

4. **질문 4 (개인화 프로필 기반 자동 추천):**  
   > "내 프로필 바탕으로 내가 지금 지원하기 제일 좋은 맞춤 대외활동 3개 추천해주고, 각각 추천하는 이유도 명확하게 알려줘."

5. **질문 5 (파일 제어 및 자소서 초안 생성):**  
   > "추천해 준 활동 중에서 첫 번째 공고 기준으로 간단한 지원동기 초안 작성해줘. 그리고 `applications` 폴더 만들어서 `cover_letter_draft.txt` 파일로 저장해줘."

### 랭그래프 스튜디오(LangGraph Studio) 실행 화면

LangGraph Studio 환경에서 에이전트 그래프가 사용자 상태를 수신하고, 동적 미들웨어를 거쳐 스킬 프로세스에 따라 도구(Tool)를 순차적으로 호출하는 실행 흐름입니다.
